# maimul.github.io: Claude Code instructions

My personal site (`index.html`) and **Today I Learned**, a newspaper-style blog (`blog/`). GitHub
Pages serves `main` with `.nojekyll`, so every committed file goes online as-is, this one included.

## How content gets here

- `blog/` is generated by `tools/export-blog.py` in my learnings journal (a separate, local repo).
  That script also fills the `<!-- blog:latest -->` block in `index.html`. Never edit either by hand;
  re-export instead.
- `blog/feed.xml` feeds the "Today I Learned" list on the GitHub profile, through a workflow in
  `maimul/maimul`. Keep its URL and RSS shape stable.
- `.github/workflows/snake.yml` builds the contribution snake into the `output` branch. The profile
  README links its raw files, so don't delete that branch.

## Rules

- **Pushing to `main` publishes.** Ask before every push.
- Posts are public articles. They cover public tools and techniques only, with no private product,
  client, employer or people names, no internal ids, hosts or paths, and no tool credits or bylines
  unless the post is about that tool. The learnings journal enforces this with its private term list and
  leak scan.
- Read `TRACKER.md` at session start and keep it current.

## Done means

Pushed with the user's OK, the Pages build is green, and every changed URL returns 200 live.
