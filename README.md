# maimul.github.io

Source for my personal site, [maimul.github.io](https://maimul.github.io): a static `index.html` served by GitHub Pages.

`blog/` is **Today I Learned**, generated from my learnings journal by its `tools/export-blog.py`, which also fills the "From the blog" section of `index.html` between the `<!-- blog:latest -->` markers. Don't edit those by hand; re-export instead.
